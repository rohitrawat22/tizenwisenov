2. Priority P0: Critical Missing Features & Blockers

These items represent incomplete or broken capabilities that block production launch:

1. PlayReady & Widevine DRM Stream Integration P0 - Fatal Blocker
Currently, WisePlayer has zero DRM handling in either Dart or native C++ code. Premium IPTV streams and legal live channels encrypted via Microsoft PlayReady or Google Widevine fail to initialize and return blank/stalled video.
Current Flaw:
  • tv.video.dart and stream_player.dart only initialize raw URI streams.
  • pubspec.yaml comments out video_player_avplay.
  • No license acquisition headers, token parsing, or challenge exchange.
Required Solution:
  • Integrate Samsung Tizen AVPlay native DRM API (webapis.avplay.setDrm("PLAYREADY", ...)).
  • Parse DRM license URL, custom HTTP headers, and SOAP/JSON challenge payloads.
  • Provide fallback to clear streams when DRM certificate handshake fails.
2. Complete Missing EPG (Electronic Program Guide) Pipeline P0 - Core Feature
In stream_player.dart, an EpgProgramModel exists, but the codebase contains zero API calls to actually fetch, parse, or populate EPG data. The comment states: "Pass a List<EpgProgramModel> in from whatever screen already fetches the EPG JSON — this widget never fetches it itself."
Current Flaw:
  • Drawer opens with empty state or null list on every live TV channel.
  • Users have no idea what is currently playing, upcoming, or past.
  • Catch-up functionality is disabled because timeline data is absent.
Required Solution:
  • Implement get_simple_data_table & XMLTV EPG endpoints in ApiRepo.
  • Build 24-hour horizontal/vertical EPG timeline grid view.
  • Implement "Now & Next" program info bar in the player overlay (OSD).
3. Build Global Search Screen (Currently 15-Line Stub) P0 - Unbuilt Screen
The "Search" navigation tab opens lib/presentation/screen_view/common/tabs/search/screens/search_screen.dart, which is currently a 15-line empty placeholder containing only Scaffold(appBar: AppBar(title: Text("SearchScreen"))).
Current Flaw:
  • Search tab is dead; users cannot look up any channel, movie, or series.
  • No on-screen keyboard optimized for TV remote D-Pad navigation.
Required Solution:
  • Implement tri-tab search: Live TV, VOD Movies, and TV Series.
  • Add fast in-memory indexing or debounce API search with visual grid results.
  • Support Tizen OS virtual keyboard with direct D-Pad cursor navigation.
4. Replace `BetterPlayer` in TV Favorites Playback P0 - Runtime Crash
lib/presentation/screen_view/common/fav/fav.video.dart imports and instantiates better_player_plus. As documented in pubspec.yaml:48, BetterPlayer is Android/iOS-only. Tapping any item in the Favorites screen triggers a fatal crash on Samsung Tizen TV.
Current Flaw:
  • MissingPluginException thrown on Tizen OS runtime.
  • Favorites player is fragmented from the main TV stream player.
Required Solution:
  • Unify favorites playback into VideoPlayerScreen (using video_player_tizen).
  • Deprecate and remove fav.video.dart completely.
5. Eliminate Hardcoded Credentials in Upload Playlist Screens P0 - Critical Security
In both upload_playlist.dart:323-325 and tv_upload_playlist_screen.dart:94-97, the upload function ignores user input and sends hardcoded external URLs and credentials (http://line.vpnworld.pro/get.php?username=15F2C2&password=...).
Current Flaw:
  • Severe security vulnerability leaking third-party Xtream credentials.
  • Users cannot upload their own M3U playlist; hardcoded data is sent every time.
Required Solution:
  • Bind nameCtrl.text.trim() and urlCtrl.text.trim() to API request payload.
  • Validate URL scheme (http/https) and M3U format prior to dispatch.

3. Priority P1: Core Smart TV Features & Player Upgrades

6. Audio Track & Subtitle Selection OSD Dialogs P1 - Player Feature
Neither VideoPlayerScreen nor TizenVideoScreen exposes audio track switching or subtitle track selection. Users watching international live streams or multi-language VOD movies cannot switch from Hindi to English or enable captions.
Required Architecture:
  • Query active audio & subtitle tracks from VideoPlayerController.
  • Create a quick-access bottom popup sheet or side drawer on TV remote Yellow button.
  • Support embedded CEA-608/708, WebVTT, and external SRT sidecars.
User Experience:
  • Clean modal showing: Track Name, Language Code (e.g. ENG, HIN, SPA), Audio Format (Stereo, 5.1).
  • Subtitle offset/sync adjustment (-5s to +5s) for desynchronized streams.
7. Numeric Remote Channel Zapping (0-9 Quick Jump) P1 - TV Remote
Traditional TV viewers use physical remote numeric keys (0 to 9) to quickly jump to a known channel number (e.g. pressing 1, 0, 4 switches directly to channel 104). Currently, number keys are ignored.
Implementation Steps:
  • Capture LogicalKeyboardKey.digit0 through digit9 in onKeyEvent.
  • Show a 2-second floating HUD badge in the top-right corner displaying typed digits.
  • After 1.5 seconds of inactivity, switch to the matched channel number.
Channel +/- & Remote Keys:
  • Map channelUp / channelDown keys to next/previous channel in current category.
  • Map mediaInfo / info key to toggle OSD metadata without pausing playback.
8. Aspect Ratio Toggle (Fit, Fill, Zoom, 16:9, 4:3) P1 - Player Feature
Legacy IPTV streams often broadcast in 4:3, letterboxed 16:9, or stretched formats. The current player hardcodes native aspect ratio with no user override, leading to black bars or distorted displays on widescreen 4K/8K TVs.
Aspect Ratio Modes Needed:
  • Auto / Original: Default video aspect ratio.
  • 16:9 Widescreen: Force 16:9 proportion.
  • 4:3 Classic: Standard definition format.
  • Fill / Stretch: Stretch to entire TV display boundary.
  • Zoom / Crop: Crop vertical bars while preserving aspect ratio.
Remote Shortcut:
  • Cycle through aspect modes instantly via Remote Blue button or player settings menu.
  • Persist user's preference in SharedPreferences per stream type (Live vs Movie).
9. Stream Buffer Resiliency & Auto-Reconnect HUD P1 - Stability
IPTV streams suffer from network fluctuations, server throttling, or temporary packet drops. Currently, any stream disruption causes tv.video.dart to silently fail over to kMp4TestUrl (bee.mp4) or throw a black screen error.
Flaws in Current Behavior:
  • Playing bee.mp4 test video confuses end users in production.
  • No auto-retry or stream reconnection loop.
Required Solution:
  • Implement 5-attempt exponential retry loop with 2s, 4s, 8s intervals.
  • Display semi-transparent HUD: "Reconnecting stream (Attempt 2 of 5)...".
  • Remove all references to test MP4 video files.
10. Dynamic Dashboard & "Continue Watching" Row P1 - Core Experience
lib/presentation/screen_view/common/tabs/homepage/screens/homepage.dart currently loads static dummy data (onboardingData) and hardcoded _PosterCard() placeholders. It does not display the user's real IPTV content.
Required Dashboard Sections:
  • Continue Watching: Movies & Series with saved playback resume progress.
  • Favorite Channels: Quick 1-click launch row for starred channels.
  • Recently Added Movies: Real Xtream VOD items sorted by release/added date.
Data Persistence:
  • Store resume timestamps in Hive (streamId, positionSeconds, duration).
  • Auto-update row whenever user exits the video player.

4. Priority P2: Quality of Life & Smart TV Optimizations

11. Automated Parental Control (18+ / Adult Lock) P2 - Compliance
Auto-scan category names containing keywords (XXX, Adult, 18+, For Adults, Erotic) and require the master PIN before revealing channel lists or thumbnails. Provide an option to hide adult categories completely from search.
12. Tizen Memory Optimization & Image Cache Clamping P2 - Performance
Samsung Smart TVs commonly have strict 1 GB to 2 GB RAM ceilings. Set PaintingBinding.instance.imageCache.maximumSizeBytes = 100 * 1024 * 1024 (100MB). Wrap channel logos in ResizeImage(..., width: 120, height: 120) to avoid holding uncompressed 1080p bitmaps in RAM.
13. User Profile & Subscription Expiry Hub (`user_profile.dart`) P2 - Missing Screen
Replace the 15-line dummy UserProfile screen with an account dashboard showing: Xtream account status, active subscription expiration date, maximum allowed concurrent connections, device MAC address, server hostname, app version, and a "Clear App Cache" button.
14. Codebase Hygiene & Redundant File Pruning P2 - Code Quality
Several architectural remnants clutter the codebase:
  • Duplicate Series Screen: lib/series/series.details.dart (46 KB) is an obsolete duplicate of serie.details.dart (57 KB) and must be deleted.
  • Unused GPS File: lib/location.dart imports geolocator packages that are meaningless on Smart TVs.
  • Portrait Lock in TV Code: Remove DeviceOrientation.portraitDown/Up in favourite_list.dart:58 which risks breaking landscape mode on TV displays.
  • Repeated Import Blocks: Deduplicate import blocks in content_option_tv.dart and fetch_phone_info_mac.dart.
